# Known limitations

- Native Pleos Navigation route identity, route geometry, progress and reliable maneuver-passage events have not been verified for a third-party companion application. Automatic playback adaptation therefore remains disabled unless an explicitly labelled simulation is used.
- The official Pleos emulator's document picker has blocked a full user-content import qualification. The bundled original demo remains the review path.
- Digital capture was used during development, but physical speaker, headphone, Bluetooth and phone-call qualification remain incomplete.
- Native Media Center behavior was tested in the emulator with the bundled catalog. It is not a guarantee of App Market approval or vehicle-wide compatibility.
- The narrative timeline supports the original demo and conservative fallbacks; it is not a continuous on-device large-language-model feature and does not claim semantic understanding of arbitrary audiobooks.
- This is a parked prototype. Driving restrictions and system-owned UI remain controlled by the host platform.
